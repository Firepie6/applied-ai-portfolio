    THE BROADER CHECK
    One policy. Twelve scenarios.
    Run the fixture set to check expected transitions, blocked actions and effect counts. Passing these cases shows consistency with this reference policy; it does not establish production reliability or model accuracy.
    The suite has not run yet.
    

    WHAT THIS DEMONSTRATES
    Workflow logic you can inspect.
    Required inputs, staff ownership, assigned-lead acceptance, duplicate-event handling, revision conflicts and an audit trail. A staff decision is an explicit event, rather than an instruction the agent can grant itself.
    WHAT A REAL DEPLOYMENT STILL NEEDS
    Adapters and operating evidence.
    Authenticated actors, durable transactional storage, a transactional outbox, calendar conflict checks, trusted classification, escalation delivery, monitoring and real-world evaluation. This browser demo provides none of those production integrations.
